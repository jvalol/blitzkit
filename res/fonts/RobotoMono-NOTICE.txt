Where it came from
------------------

This file was made in this repository, from this repository, by taking
site/public/fonts/roboto-mono-v6-latin-regular.woff and decompressing its
sfnt tables. Nothing was downloaded to add it. The output is byte for byte
the size the woff header declares for the font it wraps, 31596.
